# Физлаб — песочница двумерной физики

Онлайн-симулятор физики, который работает прямо в браузере. Ничего не нужно устанавливать: нет сборки и зависимостей, движок написан с нуля на чистом JavaScript.

## Запуск

**Онлайн:** https://ypciiiak.github.io/all-repo/

Сайт обновляется сам при каждом пуше в ветку по умолчанию (workflow `.github/workflows/pages.yml`).

Локально:
- откройте `index.html` в браузере (двойной клик тоже подойдёт), или
- запустите сервер: `npx http-server .` и откройте `http://localhost:8080`.

## Возможности

**Физика**
- Твёрдые тела: круги, прямоугольники, правильные и произвольные выпуклые многоугольники.
- Трение, упругость (отскок), сопротивление качению, сопротивление воздуха, плотность и масса.
- Соединения: пружина (частота и демпфирование), жёсткий стержень, верёвка (провисает), шарнир с мотором и ограничением угла.
- Разрушаемые соединения: у каждого есть порог силы, а нагрузка подсвечивается цветом.
- Гравитация любой величины и направления (Земля, Луна, Марс, Юпитер, невесомость) и взаимное притяжение тел для орбит.
- Управляемые моторы: стрелки ← → (например, для машинки).

**Инструменты:** выбор и перетаскивание, «пуск» с предпросмотром траектории, круг, прямоугольник, многоугольник, статичная планка, пружина, стержень, верёвка, шарнир, взрыв, магнит, ластик.

**Сценарии:** 18 встроенных: пирамида, домино, колыбель Ньютона, хаос двойного маятника, доска Гальтона, шар-разрушитель, подвесной мост, машинка, орбиты, желе, мешалка, катапульта, трение на склонах, пружинные маятники, куклы на лестнице, нагрузочный тест. Ещё есть шаблоны, которые можно вставить в любую сцену: машинка, кукла, желе, цепь, башня, шары, качели.

**Свои сценарии:** сохранение в браузере, экспорт и импорт `.json`, ссылка на сцену (сцена сжимается прямо в адрес), кнопка «Сброс» к начальному состоянию, отмена и повтор (Ctrl+Z / Ctrl+Y).

**Интерфейс:** инспектор свойств выбранного тела или соединения с живыми показаниями (скорость, высота, энергия, импульс), настройки мира и вида, светлая и тёмная темы, контекстное меню, горячие клавиши (работают и в русской раскладке), поддержка телефона (жесты щипком).

## Почему не тормозит

- Фиксированный шаг 60 Гц, подшаги с «мягкими» ограничениями (по схеме Box2D v3 soft step) и warm starting: стопки стоят ровно уже при 4 подшагах.
- Широкая фаза sweep-and-prune и упреждающие контакты: быстрые тела не пролетают сквозь стены.
- Острова и сон: успокоившиеся тела выключаются из расчёта. 600 тел засыпают примерно за 7 секунд, после этого шаг занимает около 0.05 мс.
- Рисование тел группами по цвету: одна заливка на группу, 600 тел рисуются меньше чем за 1 мс. Невидимые тела отсекаются, а кадры интерполируются для мониторов 120+ Гц.
- Без размытия фона (`backdrop-filter`) поверх анимированного холста.

## Клавиши

| Клавиша | Действие |
|---|---|
| Пробел | Пуск / пауза |
| N | Один шаг |
| Home | Сброс к началу |
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Delete | Удалить выбранное |
| Ctrl+D | Копия |
| Q / E | Повернуть (с Shift точнее) |
| F | Показать всю сцену |
| Tab | Панель свойств |
| V G C B P W S R L H X M D | Инструменты |

## Структура

```
index.html
css/style.css
js/engine/core.js      константы, формы, тела
js/engine/collide.js   столкновения (SAT + отсечение рёбер)
js/engine/joints.js    пружины, стержни, верёвки, шарниры, захват мышью
js/engine/world.js     мир: широкая фаза, решатель, сон, взрывы, притяжение
js/data.js             материалы, темы, иконки
js/serialize.js        сохранение/загрузка, ссылки
js/scenarios.js        встроенные сценарии и шаблоны
js/render.js           отрисовка
js/tools.js            инструменты
js/ui.js               панели и инспектор
js/app.js              цикл, ввод, история
```
