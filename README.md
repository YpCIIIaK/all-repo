# Физлаб 3D — песочница трёхмерной физики

Онлайн-симулятор физики прямо в браузере: ставьте тела, соединяйте их пружинами и шарнирами, запускайте моторы, стреляйте из пушки и собирайте свои сценарии.

**Онлайн:** https://ypciiiak.github.io/all-repo/ · 2D-версия: https://ypciiiak.github.io/all-repo/2d/

Сайт обновляется сам при каждом пуше в ветку по умолчанию (workflow `.github/workflows/pages.yml`).

В том же репозитории, в ветке `furniture-store`, живёт отдельный проект — мебельный магазин «Ясень» с 3D-просмотром: https://ypciiiak.github.io/all-repo/mebel/. Workflow собирает его в папку `/mebel/` при каждом пуше в любую из двух веток.

Ещё здесь лежит [`voting-loadtest/`](voting-loadtest/) — система онлайн-голосования с подтверждением по СМС (NestJS, GraphQL, PostgreSQL, Redis) и стенд нагрузочного теста к ней: 100 000 голосов за 3 часа на имитации VPS, с плохой сетью, сбоями СМС-провайдера и падениями процессов.

## Запуск локально

Страница использует ES-модули, поэтому её нужно открывать через локальный сервер, а не двойным кликом:

```
npx http-server .
```

После этого откройте `http://localhost:8080`. Сборка и установка зависимостей не нужны: библиотеки лежат в `vendor/`.

## Возможности

**Физика** — движок [Rapier](https://rapier.rs) (Rust → WebAssembly):
- формы: ящик, шар, цилиндр, капсула, конус; плотность, трение, упругость, затухание, множитель гравитации, CCD для быстрых тел;
- соединения: пружина (частота и демпфирование), верёвка, шаровой шарнир, ось с мотором и ограничением угла, сварка;
- моторы со стрелками: ↑ ↓ — газ, ← → — повороты (левая и правая сторона);
- гравитация планет, невесомость, взаимное притяжение тел (орбиты), сопротивление воздуха, точность решателя;
- сон неподвижных тел: 1000 успокоившихся тел почти не нагружают процессор.

**Инструменты:** выбор и перетаскивание (на паузе — точное перемещение, с Shift — по вертикали), пушка, пять форм (ставятся на поверхность под курсором, протяжка меняет размер), стена, пружина, верёвка, шаровой шарнир, ось, сварка, взрыв, магнит, ластик.

**Сценарии (16):** пирамида, дженга, спираль домино, боулинг, колыбель Ньютона, шар-разрушитель, подвесной мост, машинка, орбиты, мешалка, доска Гальтона, маятник-цепь, катапульта, нагрузочный тест на 1000 тел и другие. Шаблоны для вставки в любую сцену: машинка, дженга, пирамидка, шары, цепь, ряд домино.

**Свои сцены:** сохранение в браузере, экспорт и импорт `.json`, ссылка на сцену (сцена сжимается прямо в адрес), «Сброс» к начальному состоянию, отмена и повтор.

**Интерфейс:** инспектор свойств с живыми показаниями (скорость, высота, энергия, импульс), тени, туман, следы, векторы скорости, график энергии, светлая и тёмная темы, три уровня качества, контекстное меню, горячие клавиши (работают и в русской раскладке), управление на телефоне.

## Почему не тормозит

- Все тела одной формы рисуются одним вызовом (`InstancedMesh`): тысяча ящиков — одна отрисовка.
- Физика считается в WebAssembly с фиксированным шагом 60 Гц; кадры между шагами интерполируются для мониторов 120+ Гц.
- Успокоившиеся тела засыпают и выключаются из расчёта.
- Тени следуют за камерой и их можно отключить; на «экономном» качестве снижается разрешение.
- Если компьютер не успевает, время в симуляции замедляется, а не копит отставание.

## Управление

| Действие | Как |
|---|---|
| Вращать камеру | ЛКМ по пустому месту или ПКМ |
| Сдвигать камеру | Shift + ЛКМ или средняя кнопка |
| Масштаб | Колесо (при захвате тела — ближе/дальше) |
| Пуск / пауза / шаг | Пробел / N |
| Сброс к началу | Home |
| Отменить / повторить | Ctrl+Z / Ctrl+Y |
| Удалить / копия | Delete / Ctrl+D |
| Повернуть выбранное | Q / E (с Shift — точнее) |
| Показать всё | F |
| Инструменты | V G B C Y K O W S L R H J X M D |

## Структура

```
index.html            3D-версия
src/app.js            цикл, ввод, история, сохранения
src/physics.js        обёртка над Rapier: тела, соединения, запросы, воздействия
src/scene.js          отрисовка на Three.js
src/camera.js         орбитальная камера
src/tools.js          инструменты
src/scenarios.js      сценарии и шаблоны
src/serialize.js      сохранение, ссылки
src/ui.js             панели и инспектор
src/data.js           материалы, темы, иконки
vendor/               Three.js 0.179.1 (MIT), Rapier 0.19.3 (Apache-2.0)
2d/                   2D-версия на собственном движке
```
