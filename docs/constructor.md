# Конструктор корпусной мебели: как он устроен

Документ для разработчиков и технологов: что считает конструктор, по каким правилам и в каком виде отдаёт данные производству.

## Архитектура

Все размеры в ядре — в миллиметрах. Расчёт полностью отделён от отрисовки:

```
проект (JSON) ──normalize──▶ layout() ──▶ drill() ──▶ partsTable() ──▶ nest() / price() / massOf()
                                  │                         │
                                  ├──▶ buildCabinet()       ├──▶ чертежи SVG (drawings.js)
                                  │     3D (Three.js)       └──▶ CSV раскроя и присадки
                                  └──▶ проверки: errors / warns
```

| Модуль | Что делает | Зависит от браузера |
|---|---|---|
| `src/cab/model.js` | параметры, шаблоны, правила конструкции, `layout()` | нет |
| `src/cab/drill.js` | присадка: координаты всех отверстий в системе каждой детали | нет |
| `src/cab/spec.js` | спецификация, пильные размеры, кромка, масса, раскрой, стоимость, CSV | нет |
| `src/cab/drawings.js` | чертежи в SVG: фасад, разрезы, деталировка, замер ниши, карты раскроя | нет |
| `src/cab/build3d.js` | 3D-модель из результата `layout()` | Three.js |
| `src/cab/page.js` | интерфейс конструктора и документ «Проект для производства» | да |

Ядро (`model`, `drill`, `spec`) работает в Node: на нём держатся автотесты (`npm test`).

  "th": 16,                          // ЛДСП корпуса: 16 или 18 мм
  "base": "plinth", "baseH": 80,     // plinth | legs
  "doors": "hinged",                 // hinged | sliding

    { "w": "auto", "front": "door", "hinge": "auto",
      "cells": [ { "k": "drawer", "h": 180 }, { "k": "box", "h": "auto" }, { "k": "rail", "h": "auto" } ] }

Ячейки (`cells`) перечислены снизу вверх, высоты — в свету. `"auto"` делит остаток поровну. Типы ячеек: `box` — полка, `rail` — штанга, `drawer` — ящик, `shoes` — обувница, `pants` — брючница, `basket` — сетчатая корзина.

## Правила конструкции

**Корпус**
- Боковины идут на всю высоту (с цоколем — до пола). Крышка и дно стоят между боковинами.
- Перегородки — между крышкой и дном.
- Задняя стенка — ХДФ 3 мм, накладная, с отступом 2 мм от кромок. Если она больше листа 2800 × 2070, режется на части, которые стыкуются на профиле.
- Соединения — конфирматы 7 × 50: по 2 на стык при глубине до 450 мм и по 3 — глубже. Цоколь крепится на 1–2 конфирмата.

**Секции и ячейки**
- Ширина в свету = ширина корпуса − 2 боковины − перегородки. Секции «авто» делят остаток поровну. Если «авто» нет, разницу забирает последняя секция.
- Между ячейками стоит полка толщиной в плиту, между соседними ящиками полки нет.
- Полки съёмные, на полкодержателях. Под каждой полкой сверлятся три ряда System 32 (основной и ±32 мм), чтобы полку можно было переставить.

**Фасады**
- Двери распашные, накладные, с зазором 3 мм.
- Секция шире 600 мм получает две створки.
- Ящики внизу секции с дверью — накладные, со своими фасадами. Ящики выше, а также все ящики за дверями-купе — внутренние.
- С антресолью двери делятся по ближайшей к заданной высоте полке, и эта полка становится стационарной.

**Петли и ящики**
- Число петель: 2 — до 900 мм высоты двери, 3 — до 1600, 4 — до 2000, 5 — выше. Кроме того, не меньше одной петли на 6 кг массы двери.
- Позиции петель: 100 мм от краёв двери, остальные — равномерно.
- Направляющие ящиков — наибольшая длина из ряда 250…550 мм, которая помещается в глубину.

**Купе**
- Число дверей: ⌈W / 1000⌉, минимум 2. Перехлёст 30 мм. Двери идут по двум трекам.

**Ниша**
- Корпус считается по наименьшим замерам.
- Без доборов: по бокам оставляется зазор `gap`. С доборами: по 50 мм с каждой стороны, а сами доборы делаются на 20 мм шире, чтобы подрезать по стене.
- Плинтус даёт вырез в боковинах и сдвигает задний цоколь.

**Прочность**
- Прогиб полки — как у балки на двух опорах под равномерной нагрузкой: δ = 5qL⁴ / 384EI, где E = 1800 Н/мм² (ЛДСП с учётом ползучести).
- Допуск — L/250. При превышении конструктор предупреждает и предлагает сузить секцию или взять плиту 18 мм.

## Что получает производство

**Спецификация** — по строке на каждую группу одинаковых деталей (одинаковые размеры, кромка и присадка). В строке:
- чистовой и пильный размер (пильный = чистовой − кромка 2 мм на соответствующих торцах);
- толщина, количество, кромка по сторонам, направление текстуры, масса.

**Присадка** — каждое отверстие в системе координат детали:
- `X` — вдоль длины от торца L0, `Y` — вдоль ширины;
- пласть A — внутренняя у корпусных деталей и тыльная у фасадов; B — противоположная пласть; L0 и L1 — торцы;
- для каждого отверстия указаны диаметр, глубина или «сквозное» и назначение.

Какие отверстия считаются:
- конфирматы (Ø7 сквозное в пласть, Ø5 × 50 в торец);
- полкодержатели (Ø5 × 12);
- чашки петель Ø35 × 13 в 22,5 мм от кромки и два крепления Ø8;
- ответные планки (Ø5 в 37 мм от передней кромки);
- направляющие ящиков (Ø4), штангодержатели, ручки (Ø5 сквозное, межосевое 128 или 192 мм).

**Раскрой**
- Гильотинный, полосами поперёк листа 2800 × 2070 мм по пильным размерам.
- Обрезка 10 мм по краю листа, пропил 4 мм.
- Детали из декоров с текстурой дерева кладутся только вдоль волокон.

**Файлы**
- `*-raskroy.csv` и `*-prisadka.csv` — UTF-8 с BOM, разделитель «;», открываются в Excel и импортируются в программы раскроя.
- `*.json` — проект целиком, его можно снова загрузить в конструктор.
- Печать «Проекта для производства» — A4, альбомная ориентация, каждый лист со штампом.

## Проверки

Автотесты (`npm test`, файл `tests/cab.test.mjs`) проверяют:
- ширины секций и высоты ячеек сходятся с габаритами;
- фасады не пересекаются и не выходят за корпус;
- антресоль, расчёт ниши, пильные размеры;
- раскрой: детали внутри листа без наложений, все детали учтены;
- отверстия лежат на деталях, у дверей есть чашки петель;
- 300 случайных конфигураций считаются без ошибок и NaN.
