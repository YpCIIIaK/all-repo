# Fancy Cursor — расширение для браузера

Стилизует курсор на любом сайте. По умолчанию (режим «На ссылках») курсор обычный, а над ссылками и кнопками превращается в свой: кольцо наклоняется и вытягивается по направлению движения, а сама кнопка наклоняется к курсору в 3D. В режиме «Везде» свой курсор виден всегда:

- **кольцо с точкой**, которое плавно следует за мышью;
- **ссылки и кнопки**: кольцо раздувается и подсвечивается, слегка притягивается к центру кнопки (магнит);
- **текстовые поля** (в режиме «Везде») (`input`, `textarea`, `contenteditable`): свой текстовый курсор — вертикальная черта с засечками, высота подстраивается под размер шрифта поля;
- **клик**: волна расходится от курсора;
- четыре стиля: палец (своя рука-указатель, которая наклоняется по движению и качается на пружинке), кольцо, точка, инверсия (круг меняет цвета под собой);
- цвет, размер, плавность и эффекты настраиваются во всплывающем окне и сразу применяются на всех открытых вкладках.

Если в системе включено «уменьшить движение», задержка, магнит и волна отключаются сами.

## Установка

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`, в Яндекс.Браузере — `browser://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку `cursor-extension`.

После правки файлов нажмите кнопку обновления у расширения и перезагрузите вкладку.

## Файлы

| Файл | Что делает |
|---|---|
| `manifest.json` | описание расширения (Manifest V3) |
| `settings.js` | настройки по умолчанию, общие для страницы и окна настроек |
| `cursor.js` | скрипт на странице: рисует курсор, ловит наведение и клики |
| `cursor.css` | вид курсора во всех состояниях |
| `popup.html/css/js` | окно настроек |

## Ограничения

- На служебных страницах (`chrome://…`, магазин расширений) браузер не пускает расширения — там будет обычный курсор.
- Внутри встроенных фреймов (например, плеер YouTube) курсор рисуется самим фреймом, поэтому на границе фрейма возможен небольшой скачок.
