Что внутри

Демонстрация работы с базой данных, а не только CRUD.

DataLoader

Вложенные данные без N+1

Любая глубина связей стоит один SQL-запрос на тип связи. Тест проверяет: +20 проектов — то же число запросов.

tsvector + GIN

Полнотекстовый поиск

Русская и английская морфология, ранжирование ts_rank и подсветка ts_headline. Если все слова не нашлись — мягкий режим.

pg_trgm

Подсказки с опечатками

«opensaerch» → OpenSearch. Совпадения по началу слова идут первыми, потом похожие по триграммам.

keyset

Пагинация без OFFSET

Курсор по (position, id): цена страницы не растёт с её номером, записи не задваиваются.

GROUP BY

Статистика в базе

Частота навыков по проектам и местам работы считается агрегатами PostgreSQL, а не перебором в Node.

upsert

Идемпотентный сид

База сама заполняется при старте. Повторный запуск ничего не дублирует, а неизменённые данные пропускает по хэшу версии.

Redis

Кэш и лимиты

Cache-aside с версией данных и ограничение частоты запросов. Без Redis API работает как обычно.

HR-tech

Уже делал в продакшене

Keyset, идемпотентная загрузка, частотные подсказки и подсчёт стажа перенесены из поиска по базе 15+ млн профилей.

Архитектура

Резолверы принимают запрос, сервисы решают, что делать, Prisma и SQL работают с базой.
